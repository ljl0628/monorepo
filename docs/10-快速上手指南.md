# 10 - 快速上手指南

## 环境要求

开始之前，确保你的电脑上已安装：

| 工具 | 最低版本 | 检查命令 |
|------|----------|----------|
| Node.js | 16.0+ | `node -v` |
| pnpm | 9.x | `pnpm -v` |
| Git | 任意版本 | `git --version` |

如果还没安装 pnpm，运行：

```bash
npm install -g pnpm
```

## 第一步：克隆项目

```bash
git clone <仓库地址>
cd monorepo
```

## 第二步：安装依赖

在根目录执行一次命令，所有包的依赖都会被安装：

```bash
pnpm install
```

安装过程：
1. pnpm 读取 `pnpm-workspace.yaml`，发现 `apps/*` 和 `packages/*` 下的所有子项目
2. 统一下载所有 npm 依赖到全局存储
3. 在每个子项目的 `node_modules/` 中创建符号链接
4. 在需要内部包的地方创建 workspace 符号链接

安装完成后，目录结构会多出 `node_modules/` 目录：

```
monorepo/
├── node_modules/          # pnpm 的全局存储 + 工具
├── apps/
│   ├── web/node_modules/  # web 的依赖
│   └── server/node_modules/  # server 的依赖
├── packages/
│   ├── shared/node_modules/  # shared 的依赖
│   └── ui/node_modules/      # ui 的依赖
└── ...
```

## 第三步：构建所有包

```bash
pnpm build
```

这个命令会调用 Turborepo，按依赖顺序构建所有包：

```
@monorepo/shared    → 编译 TypeScript → 生成 dist/
@monorepo/ui        → 编译 TypeScript → 生成 dist/
@monorepo/server    → 编译 TypeScript → 生成 dist/
@monorepo/web       → 类型检查 + Vite 打包 → 生成 dist/
```

构建产物被 Turborepo 缓存。第二次运行如果没有代码变更，构建会瞬间完成。

## 第四步：启动开发服务器

### 启动前端

```bash
pnpm dev:web
```

- Vite 开发服务器启动在 **http://localhost:3000**
- 打开浏览器访问该地址
- 修改代码后浏览器会自动更新（热更新 / HMR）

### 启动后端

```bash
pnpm dev:server
```

- Express 服务器启动在 **http://localhost:4000**
- 修改代码后服务器会自动重启

### 同时启动前后端

打开两个终端窗口：

```bash
# 终端 1
pnpm dev:web

# 终端 2
pnpm dev:server
```

## 第五步：验证功能

### 验证前端

1. 打开浏览器访问 http://localhost:3000
2. 应该看到 "Monorepo Web" 标题
3. 点击 "Click me" 按钮应该弹出 alert

### 验证后端

```bash
# 健康检查
curl http://localhost:4000/api/health
# 预期输出：{"code":0,"data":{"status":"ok","timestamp":...},"message":"success"}

# 获取用户列表
curl http://localhost:4000/api/users
# 预期输出：{"code":0,"data":[{"id":"1","name":"Alice","email":"alice@example.com"},{"id":"2","name":"Bob","email":"bob@example.com"}],"message":"success"}
```

## 日常开发流程

### 修改共享类型

```bash
# 1. 编辑 packages/shared/src/index.ts
# 2. 不需要手动操作，前端和后端的类型会自动更新
#    - web 的 Vite 通过别名直接加载源码
#    - server 的 tsx watch 会检测到变化并重启
```

### 添加新的共享组件

```bash
# 1. 在 packages/ui/src/ 中创建新组件文件
# 2. 在 packages/ui/src/index.ts 中导出新组件
# 3. 在 apps/web 中导入使用
```

### 添加新的 API 端点

```bash
# 1. 在 apps/server/src/index.ts 中添加新路由
# 2. 如果需要新的共享类型，先在 packages/shared 中定义
```

## 常用命令速查表

| 命令 | 作用 |
|------|------|
| `pnpm install` | 安装所有依赖 |
| `pnpm build` | 构建所有包（Turborepo） |
| `pnpm build:shared` | 只构建 shared 包 |
| `pnpm build:ui` | 只构建 ui 包 |
| `pnpm build:web` | 只构建 web 应用 |
| `pnpm build:server` | 只构建 server 应用 |
| `pnpm dev:web` | 启动前端开发服务器 |
| `pnpm dev:server` | 启动后端开发服务器 |
| `pnpm lint` | 对所有包执行代码检查 |
| `pnpm clean` | 清除所有编译产物 |

## 故障排除

### 安装依赖失败

```bash
# 清除 pnpm 缓存和 node_modules
pnpm clean
rm -rf node_modules
rm -rf apps/*/node_modules
rm -rf packages/*/node_modules
rm -rf .turbo
pnpm install
```

### 构建失败

```bash
# 强制重新构建（忽略缓存）
turbo build --force

# 或者先清除再构建
pnpm clean
pnpm build
```

### 类型错误

```bash
# 从根目录执行完整的类型检查
tsc -b --verbose

# 检查特定的包
cd packages/shared && tsc -b
```

### 端口被占用

```bash
# 查看哪个进程占用了端口
# macOS / Linux
lsof -i :3000
lsof -i :4000

# Windows
netstat -ano | findstr :3000
netstat -ano | findstr :4000
```
